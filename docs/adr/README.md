# Architecture Decision Records (ADRs)

This directory is used to document significant architecture decisions for SecureCBT.
Each ADR should be written in markdown and name-numbered sequentially (e.g., `0001-record-architecture-decisions.md`).

For more details on how to write ADRs, reference industry templates (like [Michael Nygard's template](https://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions)).
